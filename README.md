# تعريب هايتل

مصدر التعريب العربي للعبة Hytale 0.7.0 وتطبيق Windows الذي يدير تركيبه واسترجاع الملفات الأصلية قبل تحديث اللعبة.

تضم `src/` النصوص العربية البالغ عددها 15,819 قيمة: 3,759 للواجهة، و11,134 للعالم، و902 لتخصيص الشخصية، و24 لقوائم الكلمات. يدعم التطبيق حفظ النسخ الأصلية والتحقق من بصمات الملفات قبل تركيب التعريب وبعده. إذا تغيرت ملفات اللعبة، يوقف التركيب حتى تُجهز حزمة موافقة للنسخة الجديدة.

## حالة الإصدار

- نسخة المصدر المستهدفة: **Hytale 0.7.0**.
- اجتاز المصدر المحلي فحص المفاتيح ومتغيرات النصوص؛ مراجعة العرض داخل اللعبة بعد الحزمة الأخيرة ما زالت مطلوبة.
- تثبيت التطبيق وحده لا يغيّر ملفات اللعبة. من داخل التطبيق، استرجع التعريب القديم أولًا إذا ظهرت رسالة تجهيزه للتحديث، ثم ركّب الحزمة الجديدة بعد إغلاق اللعبة والمشغّل.
- تنشر GitHub Actions ملف التثبيت والنسخة المحمولة من المصدر بعد نجاح الفحوص. يضم الإصدار النصوص وأدوات الإعداد فقط. يولّد التطبيق حزمة اللعبة محليًا من الملفات الأصلية على جهاز المستخدم، فلا تُرفع ملفات اللعبة أو خطوط Windows إلى GitHub.

## بنية المشروع

- `src/`: النصوص العربية الأصلية.
- `app/`: مصدر واجهة مدير التعريب.
- `installer/`: مصدر مُثبّت Windows.
- `tools/ManagePackage.ps1`: تركيب حزمة محلية واسترجاع النسخ الأصلية مع فحص البصمات.
- `tools/Build-Installer.ps1`: بناء مُثبّت واحد من المصدر، أو من حزمة محلية عند تمرير `PackageRoot`.
- `tools/Build-Portable.ps1`: إنشاء ZIP محمول من ملفات المُثبّت بعد فحصها، دون تركيب التطبيق.
- `tools/PrepareOnDevice.ps1`: إنشاء حزمة 0.7.0 من نسخة اللعبة الأصلية على جهاز المستخدم بعد التحقق من بصماتها.
- `tests/Test-Catalogs.ps1`: فحص عدد النصوص وتكرار المفاتيح.
- `tests/AuditTranslationCatalog.ps1`: مقارنة العربية بمراجع الإنجليزية المحلية بعد استخراجها من نسختك من اللعبة.
- `tools/Migrate-TranslationSource.ps1`: نقل الترجمات التي لم يتغير نصها الإنجليزي إلى نسخة لعبة جديدة، وعزل النصوص الجديدة والمتغيرة للمراجعة.

## الفحص والبناء

من جذر المشروع في Windows PowerShell:

```powershell
& .\tests\Test-Catalogs.ps1
& .\tools\SnapshotGameReferences.ps1 -GameDirectory "$env:APPDATA\Hytale\install\release\package\game\latest" -OutputDirectory .\reference-snapshot
& .\tests\AuditTranslationCatalog.ps1 -ReferenceRoot .\reference-snapshot -OutputRoot .\build\linguistic-audit
```

لبناء المُثبّت الذي يُنشر من GitHub Actions دون تركيب أي شيء:

```powershell
& .\tools\Build-Installer.ps1 -OutputPath .\dist\HytaleArabicInstaller.exe -AppVersion 0.7.0.1
```

يتطلب البناء مترجم C# المضمّن في .NET Framework على Windows. لا يجلب السكربت برامج أو ملفات من الإنترنت. عند تشغيل التعريب، ينشئ التطبيق `package/manifest.json` محليًا بعد فحص نسخة اللعبة. ترتبط هذه الحزمة بمسار اللعبة ونسختها؛ عند تحديث اللعبة يجب مراجعة النصوص الجديدة وإنشاء حزمة تناسب النسخة الجديدة.

للاستخدام دون تثبيت، نزّل `HytaleArabicPortable-<version>.zip` من صفحة Releases، وفك الضغط كاملًا في مجلد واحد، ثم افتح `HytaleArabicManager.exe`. أبقِ مجلدي `tools` و`src` بجانب ملف EXE. لا تنشئ النسخة المحمولة اختصارًا أو إدخالًا في قائمة التطبيقات المثبّتة. إذا اخترت تركيب التعريب داخل التطبيق، فسيغيّر ملفات اللعبة بعد الفحص والحفظ كالمعتاد.

عند تحديث اللعبة، خذ مرجعًا إنجليزيًا جديدًا من نسختك ثم شغّل `Migrate-TranslationSource.ps1` مع مرجع النسخة السابقة والجديدة ومجلد `src`. يخرج السكربت ترجمات النصوص المطابقة في مجلد مستقل والنصوص الجديدة أو المتغيرة في `pending-english`، فلا تظهر ترجمة قديمة على معنى جديد. راجعها قبل بناء حزمة للنسخة الجديدة.

## التحديثات

كل التزام يصل إلى `main` يشغّل الفحوص والبناء في GitHub Actions. إذا نجحت، يُنشَر إصدار جديد برقم `0.7.0.N`، وملف تثبيت EXE، ونسخة محمولة ZIP، وبصمة SHA-256 لكليهما. يفحص التطبيق أحدث إصدار منشور على GitHub عند فتحه. إذا وجد تحديثًا، يظهر زر «تحديث التطبيق» وينزّل الملف الموافق لطريقة تشغيله. النسخة المثبّتة تفتح المُثبّت بعد فحص بصمته؛ والنسخة المحمولة تفك التحديث في مجلد جديد بجانب المجلد الحالي، ثم تفتح التطبيق الجديد. يبقى المجلد المحمول القديم حتى تتمكن من الرجوع إليه أو نقل ملفاتك المحلية منه. لا يغيّر تحديث التطبيق ملفات اللعبة. إذا تعذّر الاتصال، يبقى التطبيق صالحًا للاستخدام ويمكن إعادة الفحص من الزر.

عند صدور تحديث للعبة، تُراجع النصوص الجديدة وتُبنى حزمة مناسبة ثم إصدار جديد من التطبيق؛ تعرض اللعبة نصوصها الأصلية حتى تجهز ترجمتها. لا تركّب حزمة 0.7.0 فوق نسخة أحدث.
